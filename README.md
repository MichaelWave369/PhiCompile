# ΦCompile

**Build outward. Circle back. Compile forward.**

ΦCompile is a local-first, evidence-governed knowledge compilation engine. It is designed to ingest sources without modifying originals, extract traceable claims, connect knowledge, flag possible contradictions, and produce auditable change receipts.

> Status: bootstrap. The functional proof of concept is developed and reviewed in pull requests before release.

Principles: **Ledger Above Ego**; evidence before synthesis; claims never silently become facts; human-controlled promotion and publishing.

See the first implementation pull request for the initial CLI, tests, and documentation.
